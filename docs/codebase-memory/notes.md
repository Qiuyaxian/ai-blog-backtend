# codebase-memory-mcp 注意事项

> 返回入口：[Codebase-memory-mcp 使用指南](./README.md)

- **数据完全本地**：所有处理在本地完成，代码不会离开你的机器。
- **索引持久化**：索引存入本地 SQLite，跨会话重启和上下文压缩后依然存在。
- **自动同步**：后台轮询检测文件变更，自动触发增量重新索引，无需手动操作。
- **增量索引**：基于内容哈希，只重新解析变更的文件，比全量扫描快 4 倍。
- **自更新**：`codebase-memory-mcp update` 下载最新版本、验证校验和并原子替换二进制。
- **Windows 路径**：`CBM_CACHE_DIR` 中避免使用非 ASCII 字符，否则路径会被错误解码[reference:9]。
