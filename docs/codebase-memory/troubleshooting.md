# codebase-memory-mcp 故障排查

> 返回入口：[Codebase-memory-mcp 使用指南](./README.md)

| 问题                                | 可能原因                        | 解决方案                                                                    |
| ----------------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| `/mcp` 中看不到 codebase-memory-mcp | MCP 配置未生效                  | 检查 `.cursor/mcp.json` 格式，重启 Cursor                                   |
| 二进制路径错误                      | 手动配置时路径不正确            | 使用绝对路径，或运行 `codebase-memory-mcp install` 自动配置                 |
| 索引速度慢                          | 首次索引大型仓库                | 首次索引需要时间，后续增量索引很快                                          |
| 查询结果不准确                      | 索引未覆盖部分文件              | 检查 `get_index_status`，确认索引覆盖率                                     |
| Windows SmartScreen 警告            | 未签名软件                      | 点击“更多信息” → “仍要运行”，或通过 checksums.txt 验证完整性                |
| MCP 连接超时                        | 二进制未正确执行                | 确认二进制有可执行权限，且路径不包含空格                                    |
| 索引文件不在预期位置                | `CBM_CACHE_DIR` 未生效          | 重启 Cursor，确认环境变量已正确设置；在 MCP 配置中通过 `env` 字段设置更可靠 |
| Windows 路径乱码                    | `CBM_CACHE_DIR` 含非 ASCII 字符 | 改用纯 ASCII 路径                                                           |
