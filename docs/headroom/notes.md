# Headroom 注意事项与限制

> 返回入口：[Headroom 使用指南](./README.md)

- **数据不出本机**：压缩在本地完成，prompt 和文件内容不会发送到任何地方进行压缩。
- **可逆性**：原始内容缓存在本地，模型可通过 CCR 按需检索，不丢失信息。
- **代理默认 loopback-only**：只监听 `127.0.0.1`，外部网络无法访问。
- **匿名遥测默认关闭**：需显式设置 `HEADROOM_TELEMETRY=on` 才启用。
- **输出 Token 也压缩**：Headroom 不仅压缩你发送的内容，还压缩模型写回的内容。
- **首次使用建议先跑 `audit` 模式**：观察压缩效果后再切换到 `optimize`。
