# 故障排查

> 返回入口：[Caveman 使用指南](./README.md)

## 故障排查

| 问题                         | 可能原因                    | 解决方案                                                       |
| ---------------------------- | --------------------------- | -------------------------------------------------------------- |
| `/caveman` 命令无效          | 未安装或未激活              | 运行 `npx skills add JuliusBrussee/caveman -a cursor` 重新安装 |
| 每次新会话都要重新输入       | 默认按会话激活              | 安装时添加 `--with-init` 生成 always-on 规则文件               |
| `--with-init` 未生成规则文件 | 当前目录不是 Git 仓库根目录 | 在项目根目录执行，或手动创建 `.cursor/rules/caveman.mdc`       |
| MCP 连接失败                 | `uvx` 不可用                | 先安装 uv，或改用 `pip install caveman-mcp` 后手动配置         |
| 破坏性操作仍被压缩           | 自动清晰机制未触发          | 确认操作被识别为危险操作，或手动输入 `stop caveman`            |
| AGENTS.md 中的声明不生效     | 规则文件优先级更高          | 检查 `.cursor/rules/` 下是否有覆盖规则，或改用 `.mdc` 文件     |
