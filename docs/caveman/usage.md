## 使用教程

### 基本命令

| 命令              | 效果                                      |
| ----------------- | ----------------------------------------- |
| `/caveman`        | 激活 Caveman，默认使用 `full` 级别        |
| `/caveman lite`   | 删除填充词，保留完整语法                  |
| `/caveman full`   | 经典 Caveman 模式（允许碎片句、删除冠词） |
| `/caveman ultra`  | 最大压缩，用箭头表示因果关系              |
| `/caveman wenyan` | 文言文模式                                |
| `stop caveman`    | 退出 Caveman，恢复正常模式                |

### 强度级别详解

| 级别   | 命令              | 效果                                                            | 适用场景                 |
| ------ | ----------------- | --------------------------------------------------------------- | ------------------------ |
| lite   | `/caveman lite`   | 删除填充词和客套话，保留完整句子和冠词                          | 日常对话，希望稍微简洁   |
| full   | `/caveman full`   | 默认级别，删除冠词，允许碎片句，使用短同义词                    | 大多数编码任务           |
| ultra  | `/caveman ultra`  | 最大压缩，缩写（DB/auth/req/res/fn），去掉连词，用 X→Y 表示因果 | 极简场景，追求最低 Token |
| wenyan | `/caveman wenyan` | 文言文风格，80–90% 字符减少                                     | 趣味场景或特殊需求       |

### 自动清晰机制

Caveman 在遇到以下情况时会**自动暂停压缩**，使用完整清晰的表达：

- **破坏性操作**：`DROP TABLE`、`rm -rf`、不可逆操作
- **安全警告**：可能导致数据丢失或泄露的内容
- **多步骤序列**：碎片句顺序可能导致误读的场景

清晰部分结束后，Caveman 模式会自动恢复，无需手动切换。
