## 1. 依赖总览

| 依赖          | 用途              | 协议        | 故障影响             | 缓解措施            | 负责人 | 监控入口 |
| ------------- | ----------------- | ----------- | -------------------- | ------------------- | ------ | -------- |
| MongoDB       | 持久化核心数据    | TCP         | 核心数据不可读写     | 主从、连接池、备份  |        |          |
| Redis         | 缓存、会话、限流  | TCP/RESP    | 缓存失效、登录态异常 | 哨兵/集群、降级直查 |        |          |
| 对象存储      | 封面、头像        | HTTPS/S3    | 图片无法上传/访问    | 重试、CDN 回源      |        |          |
| 邮件服务      | 验证邮件、通知    | HTTPS/SMTP  | 通知延迟或失败       | 队列重试、告警      |        |          |
| 短信服务      | 验证码            | API         | 无法登录             | 备用通道            |        |          |
| 监控/日志服务 | 日志、指标、Trace | HTTPS/Agent | 可观测性下降         | 本地缓冲、降级采样  |        |          |
