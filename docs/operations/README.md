## 关键运维指标

| 指标              | 目标        | 说明     |
| ----------------- | ----------- | -------- |
| 服务可用性        | ≥ 99.9%     | 月度统计 |
| 平均恢复时间 MTTR | ≤ 30 分钟   | 故障恢复 |
| 平均故障间隔 MTBF | ≥ 30 天     | 稳定性   |
| 告警响应时间      | P0 ≤ 5 分钟 | 应急响应 |
| 备份成功率        | 100%        | 每日备份 |
