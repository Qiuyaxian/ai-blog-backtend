# 示例与收益

> 返回入口：[Ponytail 使用指南](./README.md)

## Before / After

### 日期选择器

**普通 Agent：**

- 安装 flatpickr
- 写 wrapper 组件
- 加样式表
- 讨论时区

**Ponytail：**

```html
<!-- ponytail: browser has one -->
<input type="date" />
```

### 量化收益

| 指标                | 相对无 Skill 基线    |
| ------------------- | -------------------- |
| **代码行数（LOC）** | **-54%**（最高 94%） |
| **Token 消耗**      | **-22%**             |
| **成本**            | **-20%**             |
| **时间**            | **-27%**             |
| **安全性**          | **100%**             |

### 各任务收益

| 任务       | 代码行数变化   |
| ---------- | -------------- |
| 日期选择器 | 404 行 → 23 行 |
| 颜色选择器 | 287 行 → 23 行 |
| Dropzone   | -62%           |

收益最大的场景是存在“过度构建陷阱”时；对于本身已经很精简的代码，收益接近零。

### 与其他方案对比

| 方案                    | LOC      | Tokens   | Cost     | Time     | Safe     |
| ----------------------- | -------- | -------- | -------- | -------- | -------- |
| **ponytail**            | **-54%** | **-22%** | **-20%** | **-27%** | **100%** |
| caveman（简洁散文对照） | -20%     | +7%      | +3%      | +2%      | 100%     |
| “YAGNI + 一行”提示词    | -33%     | -14%     | -21%     | -30%     | 95%      |

Ponytail 是唯一在所有指标上都下降的方案，也是唯一在下降的同时保持 100% 安全的方案。

## 安全边界

Ponytail 的“懒”**不是粗心**。以下内容不能省略：

- 信任边界校验
- 数据丢失处理
- 安全
- 可访问性

基准测试中，“YAGNI + 一行”提示词的安全率降至 95%，而 Ponytail 保持 100%。
